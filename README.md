# Proyecto-Automatizacion-TQA

Scripts, configuraciones y pruebas automatizadas de la materia Testing y Quality
Assurance.

Contiene la suite de pruebas automatizadas que se ejecuta sobre el sistema Ritmo
Activo, junto con los archivos de configuración del entorno y los datos de prueba
necesarios para correrla. Cada prueba automatizada se corresponde con un caso de
prueba documentado en el repositorio del Proyecto Integrador.

Materia: Testing, Quality Assurance
Carrera de Ingeniería en Sistemas, Universidad Privada Franz Tamayo
